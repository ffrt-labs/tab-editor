# tab-editor (working name)

An open-source, fully-offline browser tab editor and practice player. Opens Guitar Pro files
(GP3–5, `.gpx`, `.gp`) and MusicXML, lets you write tabs as alphaTex text with a live score beside
it, and plays them back slowed down and looped.

Built on [alphaTab](https://alphatab.net). Sibling of [Gerson](https://github.com/ffrt-labs/gerson).

Status: pre-M0 — see `PRD.md`.
